# Nachweise hinter der ersten Image-Seite

Die vorbereiteten Image-Fälle beweisen späte Mappinggenerationen, aber bisher
keine späten technischen Receipts oder verwaisten Originale hinter der ersten
Reverse-Seite. Das Einzelbudget bleibt zwei Datensätze; es gibt kein Gesamtlimit.

Die tatsächlichen SQLite-/AEAD-Fixtures werden um elf technische Receipts aus
einem authentifizierten vollständigen Ergebnis erweitert. Eine gültige Variante
muss vollständig zählen; eine erst am letzten Task veränderte Objektzuordnung
muss scheitern. Zusätzlich werden zwei vollständige Dokumentoriginale mit je
eigenem Source-/Contentlauf und passendem Receipt ergänzt. Das Entfernen nur des
letzten Receipts muss beim dritten Original als fehlender Rückbezug auffallen.

Alle Änderungen betreffen ausschließlich isolierte Testbilder vor ihrer
Versiegelung. Diese Prüfungen erlauben keine Live-Schreibaktion oder gemeinsame
Wiederherstellung; der unveränderte Commanddigest bleibt ausdrücklich unbelegt.
